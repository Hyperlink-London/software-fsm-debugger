# FSM Debugger

This is a potential FSM debugger built with React Flow and TypeScript
Template used: [@xyflow/vite-react-flow-template](https://github.com/xyflow/vite-react-flow-template)

# How to install
To install, clone the repo and run this:
```bash
npm install
npm run dev
```
